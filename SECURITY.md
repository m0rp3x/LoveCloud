# Security policy

LoveCloud is an early self-hosted release for a pair, not an end-to-end encrypted service. The host operator controls stored originals, database and DataProtection keys. Read the [access model](docs/LIMITATIONS.md).

## Report privately

Use GitHub's enabled **[private vulnerability report](https://github.com/m0rp3x/LoveCloud/security/advisories/new)** for authentication bypass, unintended disclosure, data loss or other security issues. Sign in to GitHub and include the affected version/digest, a minimal synthetic reproduction, impact and relevant sanitized logs. Do not publish the exploit or personal files in a public issue.

Never send real credentials, setup URLs, TOTP seeds, recovery codes or unredacted backups. A synthetic reproduction is enough. No fixed response time or security support SLA is promised; maintainers will assess reports within their available capacity.

Only the latest published release is currently targeted for fixes. If you cannot use private reporting, do not put sensitive details in a public issue; use a minimal request asking maintainers to arrange a private channel. No unverified email address is listed.
