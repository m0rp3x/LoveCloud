# Changelog

## 0.1.0

First public release of the current LoveCloud feature set: one pair and an administrator; RU/EN setup, avatars and three themes; file/folder/album cloud with authenticated Range reads; social posts/replies/reactions with SignalR; shared recurring tasks; wishlists with private gift reservations; TOTP-protected shared area and recovery codes.

Release preparation adds Apache-2.0 licensing and third-party notices, prebuilt digest-pinned Docker distribution, persistent installation configuration, delivery/backup/restore/update checks, English/Russian README, architecture/operations documentation and a backend-free GitHub Pages interactive preview.

The release manifest and CI reports record actual PASS/FAIL/NOT RUN results. Linux amd64 is the initial release target. Real thumbnails, resumable upload, S3 and video transcoding are not included.
