# Мастер первого запуска

Установка начинается с одноразовой ссылки из `scripts/init.ps1` / `scripts/init.sh`.
Секрет находится в fragment `#token=…`, обменивается через POST и удаляется из адреса.
Сервер хранит SHA256 секретов и выдаёт отдельную HttpOnly setup-cookie на24часа.

Поля и пароли мастера остаются в памяти вкладки. После reload их вводят заново;
свои незавершённые аватарки доступны через setup-session для очистки.

## Данные завершения

`POST /api/v1/setup/complete` принимает:

```json
{
  "locale": "ru",
  "theme": "berry",
  "pair": {
    "name": "Наше маленькое облако",
    "startDate": "2026-05-18",
    "timeZone": "Europe/Moscow",
    "avatarId": null
  },
  "adminPassword": "<новый-пароль-администратора>",
  "partners": [
    {
      "username": "first_partner",
      "displayName": "Первый партнёр",
      "password": "<пароль-первого-партнёра>",
      "avatarId": null
    },
    {
      "username": "second_partner",
      "displayName": "Второй партнёр",
      "password": "<первоначальный-пароль-второго-партнёра>",
      "avatarId": null
    }
  ]
}
```

Пароли —12–256символов. `locale`: `ru` / `en`.
Темы: `berry` — Клубничное молоко, `rose` — Rose Drive, `cloud` — Cloud Atelier.
`startDate` необязательна. Аватары PNG/JPEG/WebP до2MiB загружаются отдельно;
сервер нормализует их в PNG. Не больше трёх pending-аватаров на сессию.

Завершение одной транзакцией создаёт ровно двух партнёров, сохраняет настройки,
меняет пароль bootstrap admin, закрывает setup и отзывает старые claims/сессии.
Первый партнёр входит сразу; второй обязан изменить первоначальный пароль.
Некорректный запрос откатывается целиком. Одновременно завершить setup дважды нельзя.

Мутации требуют точный Origin и `X-Setup-CSRF`. Обычная auth-cookie не заменяет
setup-cookie. После завершения ни старая ссылка, ни новый файл токена не открывают мастер.
Существующие настроенные установки при миграции сохраняют пользователей и данные.

Точные endpoints и коды ответов — в [API](API.md).
Инструкция владельцу — в [SELF_HOSTING](SELF_HOSTING.md).
