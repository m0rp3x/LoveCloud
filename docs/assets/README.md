# Изображения для README

`banner.svg` — самостоятельная векторная обложка LoveCloud в палитре
«Клубничного молока». Шрифтовые формы Caveat и Golos Text переведены в контуры;
SIL OFL лицензии исходных шрифтов лежат в `frontend/public/fonts/`.
Использованы иллюстрации проекта из `frontend/public/illustrations/`.

Скриншоты показывают действующее приложение в отдельной локальной демо-установке:
вымышленную пару «Аня + Миша», бумажные папки, оригинальные иллюстрации,
послания, общие дела и желания. Данные реального облака не использовались.
Пароли, установочные секреты, QR и recovery codes на изображения не попадали.

- `cloud.jpg` — папки и живой стол.
- `feed.jpg` — социальная лента.
- `planner.jpg` — общие дела.
- `wishes.jpg` — вишлисты.
- Старый `themes.jpg` исключён: внутри старых миниатюр тем были пиксели stock-фотографий без установленной атрибуции.
- `rose-drive.jpg`, `cloud-atelier.jpg` — те же материалы в двух других темах.

Три изображения `frontend/public/themes/` заменены соответствующими безопасными снимками `cloud.jpg`, `rose-drive.jpg`, `cloud-atelier.jpg`. Старые скриншоты прототипов с внешними фотографиями исключены из текущего выпуска.

Для новых снимков используйте такую же отдельную установку с вымышленными данными.
